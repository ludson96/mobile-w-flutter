# Todo List App

🇧🇷 Leia isto em [Português](README.md)

A simple to-do list application developed with Flutter. This project was created as part of studies on forms and navigation in Flutter.

## 📝 About the Project
This is an application that allows users to create and manage their to-do lists easily and intuitively. The idea is to simplify the organization of daily tasks.

## 🖼️ Screens (Preview)

The task addition screen allows the user to intuitively enter the task details.

## ✨ Features

- **Add Tasks**: Quickly add new tasks through a form in a modal.
- **Task Details**: Include a mandatory title and an optional description for each task.
- **Mark as Important**: Highlight the most important tasks with a star icon.
- **Form Validation**: The title field is mandatory to ensure no task is created blank.

## 🛠️ Technologies Used

- [**Dart**](https://dart.dev/): Programming language used by Flutter.
- [**Flutter**](https://flutter.dev/): Framework for developing cross-platform applications.

## 🚀 How to Run the Project

To run this project on your local machine, you will need to have Flutter installed. Then, follow the steps below:

1.  **Clone the repository** (if you are using git):
    ```bash
    git clone https://github.com/ludson96/mobile-w-flutter.git

    cd 4-formularios-e-navegacoes/todo_list
    ```

2.  **Install the dependencies** with Flutter:
    ```bash
    flutter pub get
    ```

3.  **Run the application**:
    ```bash
    flutter run
    ```
