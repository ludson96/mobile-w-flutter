# Todo List App

Um simples aplicativo de lista de tarefas desenvolvido com Flutter. Este projeto foi criado como parte dos estudos sobre formulários e navegação em Flutter.

## 📝 Sobre o Projeto
Este é um aplicativo que permite aos usuários criar e gerenciar suas listas de tarefas de forma fácil e intuitiva. A ideia é simplificar a organização das tarefas do dia a dia.

## ✨ Funcionalidades

- **Adicionar Tarefas**: Adicione novas tarefas de forma rápida através de um formulário em um modal.
- **Detalhes da Tarefa**: Inclua um título (obrigatório) e uma descrição opcional para cada tarefa.
- **Marcar como Importante**: Destaque as tarefas mais importantes com um ícone de estrela.
- **Validação de Formulário**: O campo de título é obrigatório para garantir que nenhuma tarefa seja criada em branco.

## 🛠️ Tecnologias Utilizadas

- [**Dart**](https://dart.dev/): Linguagem de programação utilizada pelo Flutter.
- [**Flutter**](https://flutter.dev/): Framework para desenvolvimento de aplicações multiplataforma

## 🚀 Como Executar o Projeto

Para rodar este projeto em sua máquina local, você precisará ter o Flutter instalado. Depois, siga os passos abaixo:

1.  **Clone o repositório** (se estiver usando git):
    ```bash
    git clone <https://github.com/ludson96/mobile-w-flutter.git>

    cd 4-formularios-e-navegacoes/todo_list
    ```

2.  **Instale as dependências** com o Flutter:
    ```bash
    flutter pub get
    ```

3.  **Execute o aplicativo**:
    ```bash
    flutter run
    ```
