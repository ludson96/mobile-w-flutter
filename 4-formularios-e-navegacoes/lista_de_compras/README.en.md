# Shopping List App 🛒

🇧🇷 Leia isto em [Português](README.md)

A simple application for managing shopping lists, developed with Flutter.

## 📝 About the Project

This application allows users to create and manage their shopping lists easily and intuitively. The goal is to simplify the organization of daily shopping.

## ✨ Features

From what I could analyze, the project is in its early stages, but the structure suggests the following functionalities:

*   Creation of shopping lists.
*   Adding items to a list.
*   Viewing existing lists.

## 🛠️ Technologies Used

- [**Dart**](https://dart.dev/): Programming language used by Flutter.
- [**Flutter**](https://flutter.dev/): Framework for cross-platform application development.

## 🚀 How to Run the Project

To run this project on your local machine, you will need to have Flutter installed. Then, follow the steps below:

1.  **Clone the repository** (if using git):
    ```bash
    git clone https://github.com/ludson96/mobile-w-flutter.git

    cd 4-formularios-e-navegacoes/lista_de_compras
    ```

2.  **Install dependencies** with Flutter:
    ```bash
    flutter pub get
    ```

3.  **Run the application**:
    ```bash
    flutter run
    ```
